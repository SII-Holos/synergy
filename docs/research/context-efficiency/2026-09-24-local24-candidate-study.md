## 失败原因与证据限制

- **Doom：2/3。** 新 VM 捕获的输出缺少要求的启动文本，但图像存在及相似度测试通过。失败测试只持续 1.0085 秒；原生测试看到图像文件存在便等待一秒并结束新 VM，不检查图像是否由新进程生成。解题尾部已经留下图像并显示过所需启动文本，故有具体的残留产物/启动时序疑点。保留 reward 0；没有额外重判，也不声称干净启动必然通过。解题阶段另有三次容器 OOM，不能把成本与结果全部归因于判题。
- **SuperJSON：191/196。** 五个实际失败涉及缺失/null stackFrames、processor hook 默认行为、cause 处理和 maxCauseDepth 归一化。
- **SQLFmt：原生 1296/1305。** 八个失败目录项因参数 ID 从 ruleset321–328 移至 337–344 而没有匹配到结果；同名等价用例在 base 报告中通过。另有一个真实断言失败：PARTITION BY 与 OPTIONS 合并到同一行。保留原生 0，不写成九个实际断言失败，也不私自重算分数。
- **采样器：8/9。** 生成样本文件包含字面量 `sample` 表头，数值读取失败；这是实际输出格式问题。
- **fd：151/152。** 自然排序的前导零数值相等行为不符合测试要求。
- **KaTeX：687/693。** 六个实际失败涉及分隔符抑制、跨列和对齐处理、错误检查，以及未定义的 `shift`。
- **KCP：原生 P2P 12/12、F2P 2/30。** Go 测试程序自身的 180 秒期限在 `TestMuxPriorityPreemption` 运行时触发。28 个失败目录项都是未完成结果占位，包含这个已启动但超时的测试；不是观察到 28 个断言失败。内部不完成的准确原因未定，不能无证据称为环境故障。外层三小时时限没有缩短。
- **KGateway：214/216。** 一组 translation fixture 不匹配同时使父项和子项失败，不是两个独立缺陷。
- **路径追踪：3/3、reward 1，原归档状态失败。** 解题 wrapper 正常退出；导出 ZIP 用 124.843 秒，随后的验证用完共享 300 秒导出期限的余量，被终止，因此没有 archive receipt。独立只读审计确认 ZIP 可读、CRC 和全部已记录文件哈希有效、50 次请求均匹配。原始 `archive_invalid;archive_missing;export_failed` 及 CLI exit 1 仍保留；没有把独立审计伪装成原生归档成功。

本轮 Boa 实际执行并通过 base 7/7 与新增 17/17。这个结果与基线原始测试未启动、独立重判 22/24 的含义不同，不能写成纯粹同环境的质量改善。

## 等待改动是否有效

本轮 24 条轨迹共 37 次阻塞 process poll、12 次 log、零次非阻塞 poll，仍出现 16 次同查询完全相同的输出。阻塞等待按每题区间去重后累计 4,361.656 秒；跨题仍可能重叠。旧基线原始工具轨迹在本次审计中不可用，因此不能给出基线轮询下降百分比。相同命令、相同输出、`ps`/`tail` 字符串都只是诊断候选，不自动等于浪费。

Polyglot 的六次阻塞等待共 1,264.225 秒；安装之前遇到仓库文件大小/哈希不一致，输出经过管道截取，随后终止安装并修复 dpkg。CompCert 六次阻塞等待共 950.390 秒，仍有静默安装、终止和修复，以及依赖生成、Coq 兼容与 runtime library 的实际解题工作。路径追踪六次阻塞等待共 1,202.201 秒；进程列表显示安装停留在 dpkg/tzdata 配置期间，Python 已经可用，agent 仍继续等待后才终止安装。可见记录没有实际输入提示，不能把这些静默都认定为已确认的交互输入等待。

Mailman 没有非阻塞 poll，只有一次 30 秒阻塞 poll 和四次 log，其中三次返回重复空输出。原生服务进程已存在而启动管道仍运行；无效 CLI/模块调用、路由诊断及重新验证也增加工作量。Doom 则包含大量编译、链接、VM 指令和寄存器修复，六条重复命令中有跨编辑重新构建；一次编辑引入的语法错误在最终验证前被修复。不能把所有额外请求归为循环查进度。

本批 CompCert 为 **53 请求 / 2,141,703 token / 2,263.041 解题秒**，Mailman 为 **49 / 2,377,625 / 1,155.748**，两题真实测试仍是 3/3。相比固定基线，CompCert token 少 7.52%，Mailman 多 94.28%。二者合计反而比基线多 27.68% token，未复现[两题试跑](2026-09-24-general-guidance-study.md)的低用量。没有把试跑的 21/24 请求、657,812/968,919 token 替换进本次 24 题表；单次轨迹和资源竞争会改变结果。
