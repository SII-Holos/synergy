# PR 10 — Settings and marketplace consistency

## Intent

Bring the settings and plugin marketplace surfaces into the same quiet workbench language: the page frame carries structure, while list items and controls stay readable without looking like stacked cards from a separate product.

## Changes

- Tighten the settings content frame so page title, section headers, and controls read as one column.
- Reduce plugin marketplace header height without changing its responsive collapse behavior.
- Soften plugin list row borders and reduce radius/padding so rows read as grouped workbench content rather than floating cards.
- Preserve keyboard focus rings, search/filter behavior, plugin loading/error/empty states, localization, and lazy plugin routes.
