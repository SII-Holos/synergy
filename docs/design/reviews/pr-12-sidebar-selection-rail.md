# PR 12 — Sidebar selection rail

## Intent

Make the active project and session easier to locate without increasing the selected background or turning every row into a card.

## Changes

- Add a two-pixel semantic leading rail to active project rows.
- Add the same rail to active session rows.
- Keep the existing selected background, hover behavior, focus behavior, collapsed flyout behavior, and responsive layout unchanged.
