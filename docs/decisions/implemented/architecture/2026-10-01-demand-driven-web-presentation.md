# Decision Record: Demand-driven Web presentation

Status: implemented

## Problem

Project entry and conversation rendering can wait for unrelated Git work, complete provider catalogs and historical bodies. A bounded message count does not bound a turn containing thousands of Parts or one enormous Markdown document. Loading the complete history to search or copy also couples those operations to the mounted viewport.

## Decision

Navigation uses a Core bootstrap whose status projection only reads its navigation page, Worktree inventory and direct file children. Expensive Worktree details, Git status, configuration and model catalogs have independent consumers and loading boundaries. Command summaries preserve deferred template execution in the selected Workspace. Shared requests release individual subscribers before cancelling the underlying operation. Cache identities include the Runtime and current resource generations; cached snapshots keep their original generation and event stamp.

File browsing initializes the selected Workspace's file resources before reading, while Scope recovery starts at background storage priority under the existing deduplicated startup and disposal owner. Writes continue to await recovery. On the large-data fixture, the previous read barrier issued roughly 81,000 foreground SQL requests before returning a direct directory listing; separating Git status alone did not remove that startup cost. A held-recovery behavioral test verifies that browsing remains available, file resources are initialized, writes wait and disposal drains the same startup.

Existing directory registration uses a read-only snapshot rather than acquiring the writer on every request; creation rechecks inside its transaction. A held writer verifies that registration lookup remains available and still rejects a replaced directory. Each display read resolves its Session once and passes the owning Scope into its internal read model and effective-history checks. Workflow status discovery reuses the indexed Session batch for persisted pauses while preserving live status precedence. These are request-local reads, not retained Session caches, so they do not attach a newer event stamp to older cached metadata.

SessionHistory owns ordered message presentation summaries and versioned Part summaries. Canonical data remains the source for model context and original metadata. Full conversation copy and text export read one effective-history snapshot independently of mounted content; portable transcript archives preserve raw recovery evidence. Header summaries bound large labels, diagnostics and diff metadata while versioned detail reads retain the originals. Historical indexes checkpoint bounded batches and recover after interruption. Migration callbacks prepare those indexes from their explicit owner identities under central migration access; they cannot call the ordinary Session admission path and wait on their own unpublished import. Web uses the existing event connection in projection mode; every state event retains its Scope epoch and sequence, while subscribed bodies start with a checkpoint and then receive version-fenced deltas. Full consumers retain their existing transport.

Virtua renders stable conversation rows keyed by individual Parts with overscan four. Each turn includes its root's Part rows explicitly because the turn-member projection contains replies. Focus and selection pin mounted rows, history prepends restore a visible identity and offset, and locating a message or Part first obtains its history window. Explicit history locations suppress automatic latest recovery until forward scrolling or an explicit return releases them, including targets shorter than the viewport. Expansion and measured-layout state live outside row components. Body caches share a byte budget across Scopes, protect active consumers and discard obsolete versions. Terminal Markdown parsing and highlighting run in a lazy worker; large documents render bounded blocks, and pathological list items, table cells and unsupported blocks fall back to bounded escaped source. Streaming retains incremental rendering. Search indexes the complete effective history independently of mounted content, using SQLite trigram FTS for longer substrings and bounded scans for short queries.

## Alternatives considered

**Cache complete bootstrap and full message pages.** Caching improves repeated reads but leaves first access, invalidation and payload growth proportional to the full dataset, and makes unrelated resources share a failure or wait.

**Virtualize complete turns.** This bounds the number of turns but permits one turn or Markdown block to allocate an unbounded DOM. Part rows and document blocks make the inner work bounded as well.

**Search and copy mounted text.** Those operations would silently omit evicted bodies and older pages. Canonical server reads and an independently prepared search projection retain full-history semantics.

## Consequences

The read model, subscription checkpoints and original-content lookups add version and recovery state. New pages and events require generated API contracts and behavioral tests for deletion, rollback, reconnect and out-of-order completion. Byte budgets are soft for content actively retained by focus, selection or visible rows; inactive content is evicted first. Exceptional oversized Markdown structures preserve source text but may lose rich layout. A single turn exceeding the message-window cap retains a bounded partial window instead of disappearing during history traversal. Custom model metadata normalizes SDK-only endpoint configuration into the validated model schema, so Core navigation remains available when no catalog endpoint exists. Historical preparation and execution-resource creation remain visible independent operations; throughput improvements do not establish a measured latency percentile without sufficient samples.

Canonical behavior is defined in [Frontend data sync](../../../architecture/frontend-data-sync.md) and [Sessions and messages](../../../architecture/session-and-messages.md).

The virtualized scroll integration follows the locked [Virtua Solid implementation](https://github.com/inokawa/virtua/blob/0.42.3/src/solid/Virtualizer.tsx); local loading boundaries follow [Solid Suspense](https://docs.solidjs.com/reference/components/suspense). Worker highlighting uses [Shiki performance guidance](https://shiki.style/guide/best-performance), and substring indexing follows the [SQLite trigram tokenizer](https://www.sqlite.org/fts5.html#the_trigram_tokenizer). Browser telemetry coalesces navigation uploads and backs off after rate limiting so measurement cannot amplify repeated interactions.

End-to-end acceptance also exercises command navigation while a terminal owns focus. The command-palette shortcut is captured before the focused control consumes it and is not delivered as terminal input. Other command bindings retain their ordinary bubbling behavior, and both listeners leave with their provider owner. A native key-consuming control verifies this boundary alongside nested transition cleanup. Explicit virtual-row anchor restoration applies only when an existing leading row shifts after a prepend and uses one native scroll adjustment. Virtua's programmatic scroll retries during measurement can otherwise overwrite a later user scroll as lazy bodies settle. Recovery that completes after historical navigation refreshes the bounded retained window instead of replacing it with latest. Summary row identities survive body invalidation, visible rows reload their Part pages and content, and latest Context has its own snapshot. Combined pages retain their first response watermarks. The production browser fixture loads historical pages, scrolls into their original text, bounds mounted rows and verifies full canonical history after reconnect. It also searches complete history and locates original text outside the retained window before returning to latest. Browser-only wrappers and the worker entry have exact-file coverage declarations naming their behavioral acceptance suites; query, row, parser and worker-client logic remains directly measured.
