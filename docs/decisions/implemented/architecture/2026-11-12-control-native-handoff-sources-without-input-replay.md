# Decision Record: Control native handoff sources without input replay

Status: implemented

## Problem

A signed machine plan does not bind a physical writer to the enrolled machine's actual Home or establish the complete native source outcome. A lost HTTP response also cannot justify replaying preparation, cancelling the original task or inventing a terminal execution-resource release.

## Decision

The native source controller snapshots its inputs and binds the actual Runtime, Store and artifact configuration. Before effects it verifies the finite service plan, current connection and canonical Session binding, then reads the current Runtime Home's existing enrollment and matches its machine, organization and deployment. A synthetic authorization in another Home cannot borrow its physical writer proof.

Preparation uses the native source coordinator and exact command barrier. After every Core tail drains, the SQL-external callback acquires and captures the public native physical lease. The final verifier reads the command watermark and checks that lease synchronously. A retained source candidate requires fresh physical capture; cached metadata cannot substitute for current ownership. The controller seals the object closure before retaining a frozen fact, while physical ownership remains held through the source choice.

Cancellation stops any current preparation wait, then invokes complete native cohort cancellation. It releases physical resources after the atomic cancelled receipt, preserves pause and never requests Continue or resubmits input. Surrender verifies its separate service permit, revalidates physical ownership and the command barrier, and commits the complete native surrender. Its signed permit cause is retained in that same transaction. Pending original grant generations block surrender rather than being declared terminal. Physical cleanup cannot clear or reverse permanent epoch facts.

Inspection reads native outcomes and retained causes. A frozen result requires the current captured physical lease; a cold or incomplete source reports the missing proof and requires explicit preparation. Inspecting an unknown result does not reacquire ownership or repeat input. Permanent cancellation and surrender remain independently reconcilable. Closing aborts controller waits, drains active preparation and releases native claims without changing epoch holds.

This primitive supplies source control only. The [integrated Environment and Workspace handoff](2026-11-14-bind-logical-environment-mapping-to-native-handoff.md) composes the public controller with the complete Working, Environment, knowledge and execution-grant owners. Those integrations cannot be replaced by a null move receipt or a fabricated cancelled Run. See [native destinations](2026-11-12-prepare-and-adopt-native-handoff-destinations.md).

## Alternatives considered

**Trust the passed Runtime ID and signing context.** Another Home could contain copied Session metadata. Enrollment must match the actual Runtime Home before its installed-writer evidence is used.

**Use a retained package as physical proof.** Cached bytes do not establish the current process, claim or installation lifetime.

**Automatically retry after an unknown send.** The source may have completed; explicit inspection can reconcile its native result without repeating preparation.

**Release a paused grant as cancelled.** Handing off the same Run is not a terminal native outcome.

## Consequences

The enrolled-home HTTP fixture uses generated clients and real member/hosted sockets. Preparation reaches the public physical owner; target reads refresh signatures through the service/source relay; independent permits drive surrender and paused activation; service ownership advances. Cancellation leaves the source paused without a target Session. Dropping the actual completion receipt yields an unknown request; inspection recovers its fact while the preparation call count stays one. The fixture also stops short HTTP observers while source native pre-freeze and destination mapping barriers remain held. Fresh inspection sees the same working operations, their connection signals remain live, and releasing the barriers completes the original jobs with one source export and one destination mapping. Every destination range still passes current service authorization. These fixtures omit Workspace, Environment, selected knowledge and task grants and do not establish those integrations. Native tests also reject an unenrolled Home and preserve the original signal when caller input changes during real signature verification.
