# Decision Record: Preserve composed presentation contracts

Status: implemented

## Problem

Independently valid component changes can disagree at their composition points. An absent plugin icon entered image rendering and failed the application shell. Binding-only Loop status removed the visible staged Blueprint choice. Compact resource actions could consume the entire heading at narrow widths, and a new error surface bypassed the shared neutral focus treatment.

## Decision

The shared icon renderer distinguishes actual image objects from missing names; an absent optional icon leaves its stable container empty. Browser regression coverage changes the same icon through absent, named and image states and exercises the assembled plugin shell.

Composer execution status remains a projection of Session binding. A separate draft entry shows the staged Blueprint title and that the next task starts it. Its removal clears only the local next-send choice. Native drag and real-controller tests cover retained editor identity and zero start, metadata or cancellation requests for draft removal.

Attachment toolbars wrap actions before squeezing their heading below its readable minimum. Error-card controls use the common neutral focus fill and canonical critical foreground token. Existing responsive and focus suites exercise the composed surfaces.

The optional prediction route documents both its domain failure and the Server shutdown response for HTTP 503. Its generated contracts and configuration defaults are checked from the registered composition. Skipping empty model-body writes does not skip the existing first-delta timing observation; meaningful-content timing remains separate.

## Alternatives considered

**Treat a staged Blueprint as an active Loop.** Rejected because it has no Session binding and must not issue runtime cancellation or status requests.

**Remove failing integration assertions or suppress the shell error.** Rejected because these failures represent user-visible composition problems. Fixtures follow the selected resource and presentation owners while retaining behavioral assertions.

**Allow labels and focus to vary by feature.** Rejected because shared input and layout rules must also hold for optional components and narrow layouts.

## Consequences

The fixes add no polling, migration, background service or history-body transfer. Draft and execution lifetimes stay separate, and incomplete optional icon metadata cannot take down the shell. Validation includes real controller behavior, native browser drags, responsive layouts, assembled plugin hosting, generated API contracts and execution timing.
