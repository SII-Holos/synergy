Create an interactive visual directly in the conversation: charts, diagrams, simulations, calendars, comparisons and design variants. Use one complete HTML fragment; inline CSS, SVG and JavaScript are supported. Maximum HTML size: 1 MiB in UTF-8. Use artifactTitle for its name and layout "wide" for a larger canvas. Use replaces with a previous visual ID to produce an immutable revision; do not edit a saved source.

The page runs in an opaque sandbox. It has no file, session, auth, tool, plugin or Electron access. HTTPS scripts, styles, fonts and images are allowed without a domain allowlist; fetch, XHR, WebSocket, forms, child frames and popups are blocked. Resource URLs can still make outbound requests: do not embed secrets. Obtain business data with normal tools and embed the resulting data. The libraries parameter loads bundled d3 (window.d3), chart (window.Chart) or mermaid (window.mermaid) before authored scripts. Prefer these to external libraries.

Use window.synergy.render after await window.synergy.render.ready. API:
- getState() returns { modelContent, uiContent }; setState({ modelContent, uiContent }) returns a Promise after durable save. Both fields together are limited to 16 KiB; use modelContent for concise semantic data the next model turn should see. uiContent is omitted from model context, not secret storage. Saving state never starts a model turn. Handle rejected saves and conflicts visibly.
- getHostContext() and addEventListener("hostcontextchange", callback) provide theme, colorScheme, locale, width, reducedMotion, viewMode and active. Read fresh state on "statechange". Pause animation when active is false. Use ResizeObserver and redraw SVG at actual width; don't squeeze fixed-width text into narrow viewports.
- requestFollowUp(text) opens a host-owned editable preview. Only the user's confirmation sends a normal session input. The existing composer draft is preserved. Never imply a request was sent before confirmation.
- controls([{id,label,type,value,min,max,step,options,group,variant}], onChange) registers number, color, boolean or select controls (12 per group, 12 select options). Values preview locally. Users can reset or submit the change summary. Use variants([{id,label,element}]) for a named carousel; selecting a variant does not call the model. Keep state serializable.
- annotate(element,{id,label}) registers a DOM/SVG region; annotate(canvas,{id,label,hitTest:(x,y)=>({id,label})}) supports Canvas objects. Host feedback includes source version, variant and selection. A screenshot may be unavailable; structural feedback remains usable.
- calendar(element,{events:[{id,title,start,end?}],onSelect}) renders a keyboard-accessible month view. Dates use YYYY-MM-DD. icon(name) returns a safe inline SVG for common controls.

Use canonical CSS variables --render-text-base/strong/weak, --render-background-base, --render-surface-base/raised-base/inset-base, --render-border-base/weak-base, --render-text-interactive-base and --render-chart-series-1 through -9. No invented tokens or component-specific light/dark colors. Let host fonts and theme update live. Use responsive grid/flex, semantic headings/labels, focus-visible, SVG text >=12px and adequate contrast. Motion uses --render-motion-duration-fast/base/slow (120/180/240ms); respect reduced motion and preserve current values during interruption. Avoid autoplay and gratuitous entry animation on restored history.

Use data-render-fullbleed on the single root to remove padding. Long content expands in the shared viewer. Export retains local interactions and state but removes host follow-up actions. The host displays the visual card automatically. The returned source Asset is JSON, not an image: if needed, reference it with an ordinary Markdown link, never image syntax. This tool confirms durable source creation, not successful rendering; do not claim frontend verification without observed evidence.
