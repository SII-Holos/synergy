Purpose and mode selection
Create an interactive visual in the conversation: charts, diagrams, simulations, calendars, comparisons or design variants. Provide exactly one of ui or html; libraries is HTML-only. Prefer ui for estimates, comparisons and parameter-driven explanations; use a complete HTML fragment for unsupported graphics, simulations or richer layouts. Use layout "wide" for a larger canvas.

Lifecycle and output
Sources are immutable: replaces creates a new version of an earlier visual in this session. The host displays the card and expands long content. The returned source Asset is JSON, not an image: link it only if needed with ordinary Markdown, never image syntax. Success confirms durable source creation, not frontend rendering; claim verification only with observed evidence.
Parameter/variant changes and state saves never start inference. Native preview edits stay local until the producing call completes; cancelled calls cannot save or request follow-ups. HTML scripts execute only after completion. Follow-ups open a host-owned editable preview; only user confirmation sends a normal session input. The existing composer draft stays independent. Never imply sending before confirmation. Export retains local interactions and state but disables host follow-ups.

Native UI
Host components appear progressively without authored scripts, CSS or network operations. Keep state keys and node IDs stable to preserve controls and focus. Node IDs must be unique; computed IDs cannot shadow state or earlier computations. Resolve {ref:"key"} from state or computed values; computations may reference only state or earlier computations. parent must name an earlier row or card. Computed inputs and bar values must be numeric, arithmetic results finite. Sliders bind to numbers in [min,max] with min < max; checkboxes to booleans; selects to strings in their options. State defaults: at most 32 values and 12 KiB; entire ui: 128 KiB (UTF-8 JSON).
Saved modelContent.parameters holds current native values for later turns. Buttons open the shared confirmation and include parameters only when the complete summary fits the host text limit.
Example ui: {"state":{"seats":8},"computed":[{"id":"price","op":"multiply","inputs":[{"ref":"seats"},29]}],"nodes":[{"id":"seats-control","type":"slider","label":"Seats","state":"seats","min":1,"max":50},{"id":"price-output","type":"metric","label":"Monthly price","value":{"ref":"price"},"prefix":"$"}]}

HTML
Maximum HTML: 1 MiB UTF-8. The opaque sandbox has no host file, session, auth, tool, plugin or Electron access. HTTPS scripts, styles, fonts and images are allowed without a domain allowlist; fetch, XHR, WebSocket, forms, child frames and popups are blocked. Resource URLs still make outbound requests: never embed secrets or leak data through them. Obtain business data with normal tools and embed results. Prefer bundled libraries: d3 (window.d3), chart (window.Chart), mermaid (window.mermaid). They load before authored scripts; do not repeat entries.

After await window.synergy.render.ready, use window.synergy.render:
- getState() returns { modelContent, uiContent }; setState({ modelContent, uiContent }) returns a Promise after durable save. Keep state JSON-serializable, within 16 KiB combined. modelContent carries concise semantics for the next model turn; uiContent is omitted from model context, not secret storage. Show rejected saves and conflicts visibly.
- getHostContext() returns theme, colorScheme, locale, width, reducedMotion, viewMode and active. Listen with addEventListener("hostcontextchange", callback) and reread getHostContext(); on "statechange", reread getState(). Pause animation when active is false.
- requestFollowUp(text) opens the shared confirmation, not a direct send.
- controls([{id,label,type,value,min,max,step,options,group,variant}], onChange) registers number, color, boolean or select controls. onChange receives an ID-to-value record (string|number|boolean) for shared and active-variant controls. Number values must be finite and in range; colors use #RRGGBB; select values belong to unique options. Limits: 12 controls/group, 96 total, 12 select options. Preview/reset locally; submit opens confirmation.
- variants([{id,label,element}]) registers a named carousel (up to 12); controls with variant apply to that ID.
- annotate(element,{id,label}) registers a DOM/SVG region; annotate(canvas,{id,label,hitTest:(x,y)=>({id,label})}) supports Canvas objects. hitTest uses element-local coordinates and may return undefined. Feedback includes source version, variant and selection even when a screenshot is unavailable. Limit: 200 regions.
- calendar(element,{events:[{id,title,start,end?}],onSelect}) renders a keyboard-accessible month view. Dates use YYYY-MM-DD; onSelect(id) receives the event ID. Limit: 500 events. icon(name) returns safe inline SVG for common controls.

Use canonical CSS variables --render-text-base/strong/weak, --render-background-base, --render-surface-base/raised-base/inset-base, --render-border-base/weak-base, --render-text-interactive-base and --render-chart-series-1 through -9. No invented tokens or component-specific light/dark palettes. Let host fonts/theme update live. Use responsive grid/flex and ResizeObserver; redraw SVG at actual width, never squeeze fixed-width text. Use semantic headings/labels, focus-visible, SVG text >=12px and adequate contrast. data-render-fullbleed on the single root removes padding.
Motion uses --render-motion-duration-fast/base/slow (120/180/240ms); respect reducedMotion and preserve current values during interruption. Avoid autoplay and gratuitous entry animation on restored history.
