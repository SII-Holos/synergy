Search the selected Workspace with hybrid (default), exact path-glob, or literal/regex content modes.

Hybrid search combines fuzzy file path matching, literal file-content search, and LSP workspace symbol lookup.

Use this when you roughly know a filename, directory name, module name, path fragment, code symbol, or an exact literal snippet in file contents.

Parameters:
- query: Search text. Empty or whitespace-only queries list files and directories only.
- limit: Maximum total merged results returned across path, content, and symbol matches. Defaults to 50; allowed range is 1-100.
- include: Optional comma-separated glob patterns to include. Applies to path and content search.
- exclude: Optional comma-separated glob patterns to exclude. Applies to path and content search.

Hybrid search behavior:
- Path search uses fuzzy matching over workspace file and directory paths.
- Content search uses fixed-string literal matching, not regex. A query with spaces searches for that exact text including spaces; it is not multi-keyword AND.
- Symbol search uses workspace symbols from an active language server. Results depend on LSP availability and may ignore include/exclude filters.
- Non-empty searches return merged results in priority order: path matches first, then content hits, then symbols.
- If path search finds no matches, the file index may be refreshed and path search retried before content and symbol results are merged.
- Empty or whitespace-only queries do not search content or symbols.

Precise search:
- mode: hybrid (default), paths, or content. The existing hybrid ranking and empty-query listing are unchanged.
- paths: query is an exact path glob. Only matching paths are returned.
- content: query is literal text by default; syntax: regex enables Ripgrep regular expressions. Invalid regex is an error, even in an empty root.
- path: precise-mode root within the selected file view; defaults to its root.
- offset: nonnegative continuation offset in precise modes, default zero. Use nextOffset to continue at the first undisplayed hit.
- syntax is only accepted for content. path/offset are not accepted for hybrid.

Precise results sort by path, line and column. Columns count Unicode characters from one. include/exclude retain comma-separated globs. Output reports mode, displayed counts, result-limit and byte-limit omissions. Search evidence covers displayed hits only and does not establish a full-file read or grant edit anchors. Use the selected file reader before editing. Dormant object searches do not allocate compute.
