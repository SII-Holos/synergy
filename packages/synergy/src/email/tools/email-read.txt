Read emails from an IMAP inbox. Use this tool when the user asks to check email, read mail, view inbox, or search for specific emails.

Usage notes:
- The `folder` parameter defaults to "INBOX" if not specified
- Use `search` to find emails by criteria. Date (`since`/`before`) and read/flag state filters are evaluated by the mail server; sender (`from`), subject, and body (`text`) filters are applied locally over a bounded newest-first window of recent mail, so narrow by date when looking for older messages. Results are returned newest-first.
- When a local search window is exhausted, the result is flagged `truncated: true` — narrow the search by date to scan older mail.
- Use `uids` to fetch specific emails by their UID (obtained from a previous search or summary)
- Use `summaries` to get a list of emails with basic info (subject, from, date, seen status) without full body content
- Use `read` to fetch full emails: decoded text/HTML bodies, plus attachment metadata (file name, size, content type). Attachment contents are not downloaded. Messages larger than the 10 MB size cap return envelope data only and are flagged `truncated: true`.
- Use `markSeen` to mark emails as read after fetching them
- The `limit` parameter controls how many results to return (default 20, max 100)
- For date-based searches, use ISO 8601 date strings (e.g., "2024-01-01")
