# Organization Protocol

Own versioned service/Runtime/client DTOs; exclude execution/storage/HTTP/UI. Reject unknown versions/fields; build strings never decide compatibility.

Run `bun run typecheck`/`bun run test`; verify mounted OpenAPI/regenerate SDKs for API-visible schemas.

Handoff proofs/plans bind purpose/ownership/operations/watermarks/connections and existing/private-copy targets; only existing requires differences. Separate `SourceReceiptPermit` signatures. Distinguish file hashes/directory CAS receipts. Refresh authority; reject system-driven human controls. Verify handoff-inspection/tampering/completion. Ranges never authorize arbitrary content.

Environment mapping requires bridge eight or newer, strict native/organization/none choices and inspected native templates; native-existing requires nine before Source freeze. Hash complete plans; retain Environment hashes in source/prepared facts. Never substitute Workspace hashes/renderer identifiers; verify `test/handoff-environment.test.ts`.

API tokens separate one-time secrets/metadata; bind explicit project/operation/expiry scope. Trusted routes select purposes; scopes never replace current authorization. Reuse Util portable account actors/optional signed token attribution. Command permits bind logical request/actor/deployment/target/epochs/sequences/finite signing window; signatures never establish current execution admission. Preserve proof bytes when sharing signing primitives; verify compiled Node imports across packages.

Hash complete inputs/targets; distinguish missing publication receipts. Skip authorization uses a separate signature domain/original attempt. Test UTF-8 bounds/changed bodies/targets/immutable accepted-effect identity separately from attempt rejection.

Desktop bridge versions require revision-bound logout phases; test old-request rejection in `test/desktop.test.ts`. Command stream frames separate transfer nonces from canonical logical IDs. Reuse command payload limits and Runtime chunk sizes; verify strict input/reply-only envelopes in `test/command-stream.test.ts`.

Decision digests bind request, source and answer. Interaction reads page pending owners and value-free winners. Bind permits to queries; verify decision-command/interaction suites.

Current execution observations belong beside immutable receipts. Bind their root and observation window to acceptance; reject observation fields in durable results.

Resources declare fixed protocols/portable model capabilities. Separate upstream config/public descriptors/secret input. Reject arbitrary Runtime options/caller-selected ownership/transport-routing credential headers. Verify `test/resource.test.ts` strict contracts.

Execution proofs bind accepted task receipts, native roots and finite machine authority separately from command acceptance. Require explicit native/cloud infrastructure; classify resource roles and exclude infrastructure from business gateways. Verify altered claims and strict contracts in `test/execution*.test.ts`.

Descriptions validate accepted intake and ordered secret-free descriptors. File signatures bind complete operations, original references and root authority. Verify cloud-files tests.

Gateway capabilities bind one call and finite resource limits. Keep machine request and worker invocation signatures separate. Verify token bounds, altered targets and signature separation in `test/gateway.test.ts`.

Shared synchronization DTOs stay strict/generation-bound. Bound notification frames/audience/sequences; reconnect never replays. Explicit shares carry portable transcript message/part DTOs/content references; Runtime owns private bodies. Reject local paths/credentials/permanent asset URLs. Keep batches contiguous/payload-hashed with explicit cursor/checkpoint semantics. API changes require mounted OpenAPI/SDK regeneration.

Private field consumption validates the same wire identities, versions, offsets and original-content state through `Read.matches`. Keep `read-content` stateless and transport-independent: typed read, awaited append and incremental hash ports only. Bound each chunk, propagate cancellation and retain partial-original status through completion. Preparation returns its progress and verified prefix offset without polling or finalizing the digest; resumption retains the same sink and hash state. Sinks publish only after the final digest succeeds.

Desktop saves bind immutable fields or attachments to the captured Session binding. Reject renderer-selected URLs, native paths and credentials; return preparation separately from saved receipts and retain partial-original state.

Publications use immutable file manifests and exact item/version/hash references. Selection updates bind a stable request, exact target, ordered page identities and a final expected sequence; page limits never become lifetime item quotas. Separate project artifact visibility from source Session visibility. Machine knowledge access reuses signed accepted execution authority and the current Session's selected versions. Page metadata and bound byte chunks without imposing a lifetime object quota.
