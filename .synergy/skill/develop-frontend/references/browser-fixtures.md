# Browser fixtures

Use standards-mode fixture documents for composed interaction tests. Include the workbench's root overflow and scroll ancestors when testing keyboard menus; a trigger that passes on an unconstrained document can fail in the real panel. Cover Enter, Space, opening arrow keys, disabled items, selection and focus return.

CSS-only fixtures retain production cascade layers and shared focus styles. Assert the control's current surface or text cue after its real transition settles, separately from focus ownership. Model scrolling with the initiating user input, then await the native scroll receipt and resulting control state; assigning `scrollTop` alone does not release an explicit latest-follow lease.

For background and foreground layout independence, compose the actual session shell, HostView wrappers and native PromptDock at both sides of the mobile breakpoint. Render the production grouping component instead of copying its DOM into the fixture. A display-contents wrapper still changes selector ancestry. Exercise content-driven growth, attachments and surrounding dock rows as well as explicit resize controls. Compare cold restored drafts with empty drafts, and shrink the viewport while editing is expanded; a cached resting height can pass the original interaction while preserving the wrong geometry. Assert canvas bounds and bitmap dimensions separately from pause and fade state. Verify short-window scrolling with a tall dock and an extension action's actual hit target, while preserving ordinary transcript flow.

For compact action toolbars, keep a wide viewport and resize only the owning pane to verify container-based adaptation. Exercise real English, Chinese and expanded catalogs with production fonts in both themes; check heading/action separation and each target's bounds, not only document overflow. Hidden text must retain localized accessible names and focus/hover help. Tooltip wrappers participate in flex sizing, so preserve their non-shrinking hit areas while titles and metadata truncate.

Pixel regressions require fonts that cover the sampled locale. `document.fonts.ready` does not prove glyph coverage: missing-glyph boxes can have different painted bounds and intensity ranges. Inspect Chromium's platform fonts and compare static color endpoints before changing a pixel threshold or product styling. Linux browser units install the declared Chinese font through CI setup; keep the behavioral assertion unchanged when repairing that prerequisite. See [localized browser fonts](../../../../docs/decisions/implemented/testing/2026-10-24-localized-browser-fonts.md).

Attachment layout regressions must retain their production presentation purpose. Automatically discovered evidence renders inside compact tool activity, while deliverables use a separate gallery; an aligned deliverable fixture does not establish evidence alignment. Compare the actual image and card edges with prose and tool rows, including wide, tall and panoramic images, and check wrapping within the scroller. Assert the rendered image fit and clickable bounds, not only the gallery container; validate full-size deliveries separately from ordinary tool thumbnails.

An opened Popover can become visible before its deferred initial focus lands. Before testing keyboard dismissal, assert that focus entered the popup; retain a separate close-focus assertion. Reopening from another action must exercise this same admission rather than relying on a fixed sleep or visibility alone.

Separate SPA benchmark warm-up from visible-readiness timing. Track the current navigation's requests through completion before opening warm counters; document `networkidle` may already be satisfied from an earlier route. Keep first reads and repeated reads distinguishable, preserve failed samples and apply the same warm-up to baseline and candidate.

For Virtua row measurements, collect resize notifications before publishing reactive size changes on an animation frame. The owning process viewport commits following and edge chrome during its own ResizeObserver delivery, before the next paint. Read geometry before writes, skip unchanged size styles and cancel pending work on disposal. Late body insertion and Markdown replacement must publish their virtual offsets before the same paint; sample after frame rendering as well as settled layout, and preserve history-shift ordering. A geometry poll after `requestAnimationFrame` can still observe DOM work that has not painted; corroborate transient reports with compositor frames before changing scheduling. For cold-body frame assertions, sample in ResizeObserver delivery with an isolated probe resized by each frame callback; a following timer can run between a DOM update and its next rendered frame. Keep the overlap threshold and verify that disabling content-size publication still fails the test. Capture `window` error events as well as Playwright `pageerror`: ResizeObserver delivery errors can bypass `pageerror`. Exercise disclosure, late hydration, viewport resize, reading anchors and rapid unmounts against both dependency entrypoints when patching a virtualizer. Record pinned patch provenance and upgrade removal criteria in [Dependency patches](../../../../patches/README.md).

Measure disclosure height only when a height transition will actually run. Parent process disclosure keeps independent virtual rows at natural height; bounded inner wrappers may animate their clipping height. Compare forced layout time as well as observer errors against the same production fixture: removing delivery errors alone does not establish a performance improvement.

Conversation readiness assertions measure pending content within the visible viewport and retain footer/body positions relative to that viewport. Resolve inherited visibility at the sampled element: a virtual row can override its container's hidden visibility. Ancestor display, content visibility and opacity still affect rendering. Delayed overscan content can change total height and scroll offset together while the reading position stays fixed; record those values for diagnosis without treating them as visible drift. Keep the pixel threshold, first-visible content completeness, bottom distance and retained-node checks. Inject visible pending content and a transient position change to verify that the frame assertions still reject both failures.

Choose a reading anchor from visible text or evidence, not a row whose bottom padding alone intersects the viewport. Font metrics differ across platforms; earlier content may grow while the actual visible paragraph stays fixed. Preserve the pixel assertion against that visible content and retain a selected or focused offscreen row to detect incorrect anchor ownership.

Wait for virtualized controls to become visible before focusing them and sending keys after deferred measurement. Assert the actual focused element so activation cannot silently reach the preceding control. After injecting history, use a browser scroll action against committed layout; reading `scrollHeight` in the same update task can still target the old range.

Also cover native movement before JavaScript scroll delivery: change the viewport offset, dispatch its wheel receipt and grow mounted content in the same task. Size compensation must use the new native position, not the last delivered scroll offset. Repeat during history prepend: native input must also end the previous distance-from-end compensation, while ordinary growth above a reader still preserves their position. Exercise both wheel/movement orders against the reading owner, including a previously compensated offset; a late input receipt must not revive the old reading anchor. Retain a separate full-application native-wheel paging check so a focused event-order fixture cannot substitute for browser integration.

Cover hiding and restoring virtualized lists between resize delivery and deferred publication. Reject notifications from targets without layout boxes during delivery, while retaining valid zero-size measurements. Read a virtual line's geometry in the same locator evaluation that resolves it; a separate element handle can be detached by renderer reflow before its box is read.

Audit opened dropdowns as well as their triggers. Feature-page choices reuse `MenuField`; verify the selection check independently of hover, themed portals, long labels and short/narrow viewports. Listbox Escape must dismiss its owning popup without clearing a multi-selection or reaching the parent Dialog. Wait for popup removal and settled trigger focus before asserting restoration.

When a shared component gains a provider dependency, update every direct DOM fixture that mounts it and run those suites together. Mount the real shared UI provider and use getter-based children so Solid constructs descendants within its owner; file preview and menu fixtures must exercise the same navigation dependencies as the product page.

Fixtures importing App modules resolve `@` to `apps/web/src`, after any specific module overrides. Update capability and subscription fixtures with the current public interfaces, and make replay fixtures return a continuous sequence or an explicit recovery response. Assert lease disposal alongside listener cleanup.

When a menu suppresses its trigger Tooltip, preserve the trigger element, focus listeners and flex-item wrapper geometry. Verify suppression inside a dialog as well as the Composer; long names must not push adjacent labels onto another line. Exercise focus → open → Escape → focus return with the real composed controls. A menu action that opens a Dialog must hand off a connected return-focus target; an unmounted menu item is not one. Distinguish a visible path Tooltip consuming Escape from a parent dialog failing to close.

When a nested Solid control must consume Escape before a document-level workspace listener, use a native `on:keydown` handler at the active control boundary; delegated `onKeyDown` runs after document listeners. Test that Escape closes only the nested control and returns focus without navigating or closing its parent surface.
