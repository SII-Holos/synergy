## Resource Workspace changes

Exercise new-tab cards and the resource menu together through the real panel registry and Workbench provider. Cover registration, removal, relabeling, Session availability and singleton open/close changes; compare order, labels and icons. Verify native Browser registration with and without its platform bridge and Runtime capability. Listing metadata must not load panels or create pages. Add enough plugin resources and a long title to check wrapping, scrolling and keyboard reachability in narrow and short windows.

For a narrow document navigation drawer, measure the backdrop as well as the drawer against resource content bounds. Keep its portal in that positioned content, preserve the toolbar and conversation hit targets, and inherit the enclosing Workspace focus boundary. Verify same-click disclosure dismissal, outside-focus preservation, backdrop dismissal and nested menu/dialog Escape order; removing a global blur alone does not remove global interaction blocking. Exercise the actual WorkbenchSurface event handlers as well as a shared modal host; moving a portal inside the resource changes which ancestor receives keyboard events. Check Tab at the final drawer control in an enclosing modal. Choose that control while opening effects are still pending, finish the entry animation, and verify the choice survives before pressing Tab; waiting for default autofocus first conceals focus-stealing races. Mount the real resource strip with multiple tabs and activate a later tab before testing forward and reverse Tab wrapping or drawer dismissal. Hidden menu anchors can retain layout rectangles, so assert the actual visible focus destination rather than only containment.

For presentation transitions, sample actual element bounds on animation frames rather than checking only settled layouts. Keep the side surface's right edge and presentation controls stationary through opening, fullscreen and restore, including frames narrower than the control group. Compare the closed entry and open collapse control's bounds. Exercise normal motion, reduced motion and rapid reversals in the composed Shell with its navigation width transition.

Render the actual Session toolbar when verifying Workspace entry geometry. Measure SVG bounds as well as the hit area through closed and open layouts; a retained button box can still contain a differently sized glyph. The portaled entry's reserved space must leave the same gap as adjacent toolbar actions, including when narrow Session columns move secondary actions into the menu.

Grouped controls need distinct group and segment surfaces. Verify moving between segments after a pointer click, keyboard focus, pressed state and an open menu whose focus moved into its portal; both themes must preserve geometry and the shared feedback duration.

Exercise tab closure with the real Workbench provider and resource strip. Verify independent close hover in both themes, a held close press past drag activation, ordinary body dragging, active/inactive and final-tab removal, pending/denied protection, concurrent closes and Session changes during protection. Assert the complete tab collection after settlement; checking only the visible active content misses intermediate restoration that creates extra tabs. Direct pointer handlers must stop drag activation before an ancestor's native listener; delegated handlers run too late for that purpose.

Keep split-layout constraints independent of the presentation they select. An automatic overlay that hides navigation must not derive its breakpoint from the resulting enlarged Session bounds. Verify an expanded navigation rail at the breakpoint across consecutive frames, then widen the window and confirm the saved split size and draft return.

Trace shell presentation, resource references, navigation preferences and editing state separately. Document clicks replace the current same-type resource through its domain close policy; explicit new-tab actions preserve multiple documents. Test late saves, conflicts, deletion, local backup failure and refresh recovery against the captured document and baseline. Keep editor history in the document controller, disable old-view transaction dispatch before retaining an unmounted editor, and initialize replacement formatting elements as hidden before mounting a retained view. Menu items render actual localized text and share direction-key navigation. Disclosure state reads actual drawer visibility; a child with its own Explorer header owns the drawer heading and close action. Wait for overlay dismissal and focus restoration before asserting returned focus. Persist manual Workspace choices and the one-output allowance; history, replay and background tasks cannot reveal it. Observe resource output through canonical assistant messages and their parts, not the user-only turn projection. Verify the 710px overlay and 520px navigation-drawer thresholds, user-size restoration, focus containment and both themes on the combined product page. The mobile modal host supplies accessibility and focus containment while the shared resource strip supplies its visible chrome.

For message resources, use the canonical `ResourceReference` parser and one asynchronous host opener. Resource dialogs must receive that same controller through their own render owner; verify the image preview’s source action using the real host. Replace transient navigation before opening a reader so remounting cannot replay an older location or duplicate notices. Carry the initiating control into asynchronous source navigation; completing an older request must not take focus from a different reference or the composer. Test streamed, settled and user Markdown, structured composer references, recycled virtual blocks and document-relative resources with the same captured Workspace and generation. Cover repeated line/column/range, heading and PDF navigation; duplicate basenames in different workspaces; absent, removed and rebound origins; encoded filenames; invalid protocols; modifier/keyboard activation; dirty drafts; and a newer request or session change during reads and close protection. An unresolved origin requires an explicit choice, never current-directory substitution. Verify immutable Asset bytes and model policy independently of current-file navigation. Exercise a reader opened before terminal settlement, then close it and verify focus returns to the replacement link. Measure image/node identity and layout during live deltas, terminal handoff and theme/size changes. Format support has one capability table shared by files and attachments; preserve reader byte limits and immutable downloads without requiring old tool bodies to stay mounted. Keep inline data-image and blob previews in this pipeline; preview permission must not grant browser navigation to those URLs. Preserve attachment labels and copy a structured source when no URL exists, hiding copy when no reference exists.

For browser-local document readers, validate actual streamed decompression in a disposable Worker before invoking a format adapter. Exclude external relationships before DOM rendering, sanitize generated content and use an opaque preview frame with a restrictive CSP. Distinguish file failures without throwing into the app shell, preserve original downloads, and reject late results even when transports ignore cancellation. Use independently lazy format entries and self-built multi-page fixtures to verify fidelity and limits; see [Office attachment reading](../../../../docs/decisions/implemented/feature/2026-10-01-office-attachment-reading.md).

## Verify File Review and Restoration

Use live browser locator actions when selecting lines after a virtualized layout change. A locator evaluation can retain a node that the viewer removes before activation; a synthetic click on that detached node does not exercise user input. Cover rapid layout changes, both diff sides and Shift ranges with native pointer and keyboard actions under browser CPU throttling.

Treat compact diff rows as metadata: absent patches still require a captured-content read. Keep recording state separate from content loading and empty results, and show an explicit retry after terminal transport errors. Large comparisons need bounded concurrent reads, version-keyed projection and highlight caches and real viewer virtualization checks; placeholder metadata must never share a filename-only highlight cache with later full content. Display settings must never alter canonical patches or comment excerpts. Verify that reading switches update a stable button without removing keyboard focus.

Use backend turn/session net projections; do not sum tool patches or infer capture quality from tool status. Preserve card and open-file identity through pending/ready/partial updates. Historical expansion must use the generated history endpoint, never the current file reader. Load restoration dialogs before mounting them on the modal stack, then verify keyboard focus, Escape and return focus. Preview first, confirm the returned identity, retain partial outcomes and retry lost replies with the same identity. See [Sessions and messages](../../../../docs/architecture/session-and-messages.md#turn-diffs).

For first-send and process status changes, preserve one current activity projection from preparation through canonical execution. Clear only the validated captured draft before asynchronous setup; carry later edits, attachments and context into the created session. Publish stage changes at actual operation boundaries, including worker admission and active scheduler calls. Never infer current activity from lazy rendered Parts or raw diagnostic descriptions. Use the shared error card for recovery, release provisional activity at canonical handoff, and exercise collapsed status, lost receipts, explicit retry and typing during preparation in an isolated production Web instance.

First-send continuity tests must retain actual user-message, attachment, process-trigger, viewport and composer nodes across delayed preflight, creation, storage readiness and canonical execution. Include the real native plugin page outlet and asynchronous router commit in mounting regressions; keep replacement plugin pages' service-release tests separate. Couple lease handoff and navigation in one Solid transition instead of a synchronous batch. Render the captured submission through the existing lease and shared renderer; never build a second simplified preview. Allocate Part IDs once and use the same canonical order for optimistic summaries and bodies. Let matching runtime activity supersede local receipts, and keep the lease until matching cached bodies and authoritative execution can replace its content and activity. Consume arrival motion on the first local paint. Hold transient inert hydration long enough to lose browser focus; restore the retained control only if focus has not moved to another control. Test accepted message aliases, reduced motion and 375 px before claiming continuity from screenshots alone.
